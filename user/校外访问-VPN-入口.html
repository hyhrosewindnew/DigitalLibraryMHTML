常见问题 · FAQ

登录提示"账号或密码错误"怎么办？▾
请先在统一身份认证中心核对账号密码（学校 OA / 教务系统同账号）。如忘记密码，请点击登录页"忘记密码"链接自助重置，或携带证件至网络信息中心（行政楼 305） 重置。
登录成功后还是无法访问数据库？▾
请按顺序排查：① 清除浏览器缓存与 Cookie 重新登录；② 更换 Chrome / Edge 浏览器；③ 关闭浏览器代理插件；④ 确认校园账号状态正常。如仍无法访问，请联系技术热线 0000-1234569。
WebVPN 与 CARSI有什么区别？▾
WebVPN：通用方案，登录后通过校内网关访问所有资源，适合检索、下载等综合场景；CARSI：联邦认证，无需 VPN 直接原站访问，体验更原生，适合特定数据库使用。
毕业生 / 校友还能访问吗？▾
应届毕业生毕业后 1 年内保留访问权限。如已毕业，可办理校友卡（每年 50 元）继续使用部分资源。详情请咨询校友会办公室。
在校内访问需要使用 VPN 吗？▾
不需要。在校内（连接校园网或信航 WiFi）可直接访问所有数据库，无需任何认证。WebVPN / CARSI 仅限校外使用。
下载全文提示"权限不足"怎么办？▾
可能因访问并发数超限（数据库对单 IP 的并发数有限制），请等待 5-10 分钟后重试；如持续报错请联系图书馆技术部处理。
