文献传递
从国内外合作馆获取本馆未收藏的期刊论文、会议论文、学位论文等；72 小时内到馆通知。
  • 本馆 + 800+ 国内外合作馆互通
  • 期刊 / 会议 / 学位 / 标准文献
  • 免费额度：本科 10 篇 / 学期
  • 研究生 / 教师 30 篇 / 学期
🔍
查收查引
为师生提供 SCI、EI、CSSCI、CSCD 等收录证明及引用检索服务，3-5 个工作日出具报告。
  • 支持 50+ 国际 / 国内数据库
  • SCI / SSCI / EI / CPCI / CSSCI
  • 出具加盖公章的检索证明
  • 免费额度：本科 2 次 / 学期
🎓
信息素养培训
为学院 / 社团 / 课题组提供定制化培训，涵盖文献检索、数据库使用、学术写作工具等。
  • 培训时长 30-90 分钟
  • 线上 / 线下双模式
  • 本科生 / 研究生全覆盖
  • 免费参与，不计入预约次数
📊
学科分析报告
为学院 / 课题组提供学科热点、学者分布、文献趋势等定制分析报告（5 个工作日交付）。
  • 学科热点前沿追踪
  • 核心学者 / 机构分布
  • 学科研究趋势可视化
  • 免费 1 次 / 学期 / 学院
📚
荐购 / 馆藏建设
师生可推荐本馆应采购的图书、期刊、数据库；馆员会评估后纳入采购计划。
  • 图书 / 期刊 / 数据库 / 试用数据库
  • 推荐后 7 个工作日内回复
  • 到馆后通知推荐人优先借阅
  • 本科每学期 5 本，研究生 / 教师 10 本
🌐
学术资源导航
为师生提供计算机、航空、文学、经济等学科的优质免费/付费学术资源导航。
  • 学科专业资源大全
  • 免费 / 试用数据库汇总
  • 校外访问指南（VPN / CARSI）
  • 随时可看，无需预约
💡 温馨提示：
  • 服务时间：周一至周五 08:00-17:30，非工作时间提交会顺延至次日处理
  • 急件 / 加急处理请直接电话联系馆员；周五 16:00 后提交的文献传递将顺延至下周一
  • 本科生与研究生均可使用全部学科服务；校外读者暂不支持查收查引、文献传递等依赖本校资源的服务
